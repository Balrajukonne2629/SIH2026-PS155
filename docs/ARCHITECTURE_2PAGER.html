03 Subsystem Mechanism Diagrams (Deep Dive)

📐 Diagram A: M × N Vendor Decoupling

Vendors normalize to a single Common Security Model (CSM), avoiding 9 separate scanners.

[Cisco IOS-XE] --\ [Juniper Junos] ---> [Vendor Adapter] ---> [ CSM JSON ] [Arista EOS] --/ (Normalization) (Contract) | +-------------------------+ v v [CIS Benchmark v2.2.1] [DISA-STIG V3R7]

• Evaluators query only normalized dot-paths (services.ssh.version).
• Adding a vendor requires 1 adapter; compliance evaluators stay unchanged.

🤖 Diagram B: Human-in-the-Loop AI Boundary

AI is strictly advisory; unmapped syntax requires authenticated human sign-off.

Unmapped Line (Parser) │ ▼ Local AI Suggester (DistilBERT/SLM) │ ▼ (Draft Rule) pending_suggestions.json [Staging Queue] │ ▼ [Human Security Officer] ├── [REJECT] ──> Discard & Audit Log └── [APPROVE] ──> trusted_mappings.json ──> Active Rules

• Zero AI auto-promotion. AI cannot approve its own suggestions.
• UNKNOWN status is preserved until human reviewer confirms rule.

🛡️ Diagram C: SHA-256 Hash Chaining

Each block recursively hashes the predecessor block, guaranteeing bit-level tamper proof.

BLOCK #1 (Genesis) BLOCK #2 +------------------------+ +------------------------+ | Prev: 0000000000000... | | Prev: 8f3a9e1b2c4d5... | | Config: 4a2b6c8d... | ==> | Config: 9b1c3d5e... | | Hash: 8f3a9e1b2c4d5... | | Hash: a1b2c3d4e5f60... | +------------------------+ +------------------------+ │ ▼ [Vector QR Code on PDF]

• H(n) = SHA256(Canonical_JSON(Block_n || H(n-1)))
• Tamper detection runs in <1ms; invalidates all downstream blocks.

⚡ Diagram D: Static AST Sandboxing

AST analysis blocks code injection before Jinja2 template execution.

Remediation Template (.j2) │ ▼ [ ast_safety.py (Static AST Safety Guard) ] ├── BLOCKS Builtins: eval, exec, __import__, open ├── BLOCKS Modules : os, sys, subprocess, socket └── BLOCKS Dunders : __globals__, __subclasses__ │ ▼ PASS Display-Only CLI Preview (Zero Side-Effects on Network)

• Zero Remote Code Execution (RCE) surface.
• Remediations generate display-only preview CLI blocks.
